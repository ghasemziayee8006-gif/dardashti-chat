# دردشتي 💬

تطبيق دردشة **حقيقي** بواجهة عربية بأسلوب تليجرام: حسابات فعلية، بحث عن أي شخص بمعرّفه (`@username`)، دردشة لحظية بين الأجهزة، ومكالمات صوتية ومرئية **مع مشاركة الشاشة** — مبني على Next.js + Socket.io + WebRTC.

## ✨ المميزات الحقيقية (تعمل بين جهازين فعليين)

| الميزة | الوصف |
|---|---|
| 👤 حسابات حقيقية | تسجيل حساب باسم معروض + معرّف فريد + كلمة مرور (مشفّرة)، ويُحفظ في قاعدة بيانات SQLite على الخادم |
| 🔍 بحث عام عن المستخدمين | اكتب معرّف صديقك فيبحث الخادم في كل الحسابات المسجلة — تظهر بطاقته مع حالته (متصل الآن / آخر ظهور) |
| 💬 دردشة لحظية | رسائل فورية عبر Socket.io، مؤشر «يكتب الآن…»، علامتا الإرسال والقراءة، عدّاد غير المقروء، والسجل محفوظ في قاعدة البيانات |
| 📞 مكالمات صوتية وفيديو | رنين حقيقي مع نغمة واهتزاز، قبول/رفض، اتصال WebRTC مباشر بين الطرفين، كتم المايك وإيقاف الكاميرا، وسجل المكالمات يظهر في المحادثة |
| 🖥️ مشاركة الشاشة | زر «مشاركة الشاشة» داخل المكالمة — تُبثّ شاشتك فعلياً للطرف الآخر عبر WebRTC (`getDisplayMedia`)، ويرى هو ما تشاركه مع تنبيه واضح |
| 🟢 حالة الاتصال | تواجد لحظي: «متصل الآن» و«آخر ظهور…» لكل حساب |
| 📱 تطبيق أندرويد | APK جاهز يفتح التطبيق مباشرة، يعمل بدون إنترنت بشاشة عربية أنيقة، ويدعم بقاء تسجيل الدخول |

## 🏗️ البنية التقنية

```
┌───────────────────────────── المتصفح / تطبيق أندرويد ─────────────────────────────┐
│   واجهة React (Next.js 16) — دردشة + بحث + مكالمات + مشاركة شاشة (WebRTC)          │
└──────────────┬──────────────────────────────┬─────────────────────────────────────┘
               │ REST (تسجيل/دخول/بحث)         │ Socket.io (لحظي) + WebRTC (P2P)
┌──────────────▼──────────────┐   ┌───────────▼──────────────────────────────────┐
│  call-service :3004         │   │  call-service :3003 (Socket.io)              │
│  تسجيل، دخول، بحث (توكن)     │   │  تواجد، رسائل، إشارات مكالمات، مشاركة شاشة    │
└──────────────┬──────────────┘   └───────────┬──────────────────────────────────┘
               └──────────────► SQLite (db/chat.db) ◄─────────────┘
                                الحسابات + الرسائل + سجل المكالمات
```

- `src/` — واجهة Next.js (المكوّنات في `src/components/dm/` والمنطق في `src/hooks/use-call.ts` و`src/lib/dm/`)
- `mini-services/call-service/` — خادم الحسابات والدردشة (Bun + Socket.io + SQLite) — يبدأ تلقائياً مع الخادم
- `android/` — تطبيق أندرويد (عميل WebView رفيع لعنوان الخادم)
- `landing/` — صفحة تعريفية تُنشر على GitHub Pages

## 🚀 التشغيل

```bash
# 1) تثبيت الحزم
bun install
cd mini-services/call-service && bun install && cd ../..

# 2) شغّل الواجهة (يبدأ خادم الدردشة تلقائياً عبر instrumentation)
bun run dev

# 3) افتح http://localhost:3000 — أنشئ حسابك ثم ابحث عن معرّف صديقك
```

لتجربة الدردشة والمكالمة بنفسك الآن: افتح التطبيق في تبويبين وأنشئ حسابين مختلفين — كل تبويب يحتفظ بجلسته.

## 📱 بناء APK

عبر **GitHub Actions** تلقائياً عند أي تعديل على مجلد `android/` — ستجد الملف في [Releases](../../releases).

يدوياً:
```bash
cd android
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
# الملف: app/build/outputs/apk/debug/app-debug.apk
```

> يعمل APK بدون إنترنت (شاشة «لا يوجد اتصال» أنيقة + إعادة محاولة)، وعنوان الخادم قابل للتغيير من داخل التطبيق.

## 🧪 ملاحظات

- مكالمات WebRTC تعمل مباشرة بين الطرفين عبر STUN العام — على بعض شبكات الجوال الصارمة قد تحتاج TURN (خطوة مستقبلية).
- مشاركة الشاشة الحقيقية مدعومة في المتصفحات الحديثة؛ وفي تطبيق أندرويد (WebView لا يدعم التقاط الشاشة) يعمل زر المشاركة بوضع عرض تجريبي متحرك يُبثّ فعلياً للطرف الآخر عبر نفس قناة WebRTC.
- كلمات المرور مشفّرة (bcrypt) والتوكنات موقّعة HMAC بصلاحية 30 يوماً.
